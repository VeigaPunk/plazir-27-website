# plazir-27-website

The Plazir frontier operation site — matte black, terminal-native, single page.

**plazir-27**: the project name meshes with the concept — Plazir in 2027, AGI reached,
**ufo-fsd launching at escape velocity**: full self-driving orchestration. From lazy prompts,
the engine self-iterates, adjusts routes, lanes, delegations, and agents dynamically mid-run —
a continuously self-improving umwelt frontier orchestration.

**Sections:** ufo-fsd doctrine (the golden map, target: escape velocity) · the distilled
conversation · current art (xbgst-kimi / xbgst-codex / xbgst-gdsp-fknpft — the public build)
· substrate map · frontier log · the dream.

## Stack

Plain static HTML/CSS/JS. No build step. `index.html` + `style.css` + `main.js`.
The dream-section vessel art is embedded as a WebP data URI — zero external assets except
one Google Fonts pull (JetBrains Mono, swap-safe with mono fallbacks).

- Generative ASCII hero field (the touch — two traces, one spark), pointer-reactive
- Boot overlay, numbered section markers, char-grid rhythm
- Red accent on matte black. Monospace everywhere. 文明-safe font stack.

## Hosting

GitHub Pages-ready: Settings → Pages → deploy from `main` / root.
Or any static host — there is nothing to compile.

## Doctrine

> Frontier is not a place. It is the practice of keeping the map true
> while everything underneath it changes.

No prior art. Only current art, done live.
